ℹ About TicketChain

TicketChain uses an ERC-20 smart contract (TicketToken / TKT) deployed on the Ethereum Sepolia Testnet. Each ticket is represented as one TKT token. Tickets are purchased by sending SETH to the contract, which mints a token directly to the buyer's wallet. Tokens can then be verified by a doorman or returned to the vendor via a standard ERC-20 transfer.
